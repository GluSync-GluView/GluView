Choosing your sensor now happens in one place: on the Sensor tab, tap Set up sensor (or Change sensor) and follow the wizard. The "Data source" selector is gone; the change only applies when you finish the wizard, so going back halfway changes nothing. To receive readings only from GluSync again, use "Stop using this sensor". "Coming soon" sensors show up in the wizard and, when testing is open, you can ask to test them right there.
