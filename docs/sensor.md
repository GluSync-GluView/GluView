# Configurar o sensor (paciente)

O GluView lê o sensor CGM direto por Bluetooth — sem precisar do app oficial do fabricante.

## Sensores suportados

- **Sibionics** (CGM chinês)
- **Freestyle Libre 2 Plus**

## Pareamento

1. **Ajustes → Fonte de dados**, escolha o sensor.
2. Toque em **Configurar sensor BLE** (Sibionics) ou **Ativar sensor (NFC)** (Libre 2 Plus,
   encoste o celular no sensor pra ativar).
3. Siga as instruções na tela — o app explica cada passo.
4. Depois de pareado, a Home passa a mostrar a glicemia ao vivo e o status do sensor
   (conectado, dias de uso, bateria).

## Avisos do sensor

Em **Ajustes → Fonte de dados → Aviso de saúde do sensor**, dá pra configurar avisos de
"sem sinal" e "sensor além da vida nominal" — são só informativos, **nunca interrompem a
leitura**.

## Histórico de sensores

A tela de pareamento mostra os últimos sensores usados (até 3 meses), útil pra saber quando
trocar o próximo.
