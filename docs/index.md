# GluView — Documentação

Bem-vindo(a)! O GluView é um app gratuito, de código aberto e sem fins lucrativos de
monitoramento de glicemia, para quem tem diabetes (paciente) e para quem acompanha alguém com
diabetes (seguidor). Ele **não substitui o aplicativo oficial do fabricante do sensor** — leia o
[aviso médico e de boa-fé](aviso-medico.md) antes de usar.

## Está com problema?

A maioria das dúvidas está no [FAQ](faq.md). Se for um bug, descreva o que aconteceu e,
se possível, exporte os logs em **Ajustes → Diagnóstico → Ver e exportar logs**.
