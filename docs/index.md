# GluView — Documentação

Bem-vindo(a)! O GluView é um app de monitoramento de glicemia para quem tem diabetes
(paciente) e para quem acompanha alguém com diabetes (seguidor).

## Comece por aqui

1. [Instalação](instalacao.md) — como baixar e instalar o app
2. [Primeiros passos](primeiros-passos.md) — criar conta, ou usar 100% local
3. [Configurar o sensor](sensor.md) — pareamento Bluetooth do CGM
4. [Acompanhamento (seguidor)](acompanhamento.md) — convidar/ser convidado, múltiplos pacientes
5. [Wearables](wearables.md) — Mi Band e outros
6. [Perguntas frequentes](faq.md)
7. [Aviso médico](aviso-medico.md) — leia antes de usar

## Está com problema?

A maioria das dúvidas está no [FAQ](faq.md). Se for um bug, descreva o que aconteceu e,
se possível, exporte os logs em **Ajustes → Diagnóstico → Ver e exportar logs**.
